Website Performance & SEO Audit Delivered

iAC Studio — Freelance · Jun – Aug 2026
Freelance Data Analyst

iAC Studio needed to know where its website was losing speed and search visibility — and what to fix first. I built an automated, reproducible audit that pulls live data from several sources, scores the site on mobile and desktop, and converts every finding into a prioritized action plan.

  • Built an automated, reproducible audit report in R Markdown pulling live data from the Google PageSpeed Insights API, HTML scraping (rvest) and server response headers.
  • Measured Lighthouse scores and Core Web Vitals across mobile and desktop to pinpoint where the site was losing speed and search visibility.
  • Audited on-page SEO — title/meta tags, heading hierarchy, link profile, image alt-text coverage — plus security headers and the site's technology stack.
  • Developed rule-based logic that converts findings into a High/Medium priority action plan, delivered as HTML, Word and PDF with ggplot2 charts.

2.1

ICT & Economic Development in 50 Developing Countries Research

Research Project — 2010–2022 panel data
ResearcherEconometrician

Which kinds of ICT drive economic growth, and what do they do to employment? I assembled the panel myself, solved a multicollinearity problem with a composite index, and estimated dynamic growth models and fixed-effects employment models — then validated them with a full battery of diagnostic tests.

  • Assembled a 650-observation country-year panel from World Bank (WDI), ITU, ILO and Worldwide Governance Indicators data.
  • Constructed a composite ICT index using Principal Component Analysis (71.6% variance explained) to resolve multicollinearity flagged by VIF testing.
  • Estimated two-step System GMM growth models and fixed-effects employment models, validated with IPS unit-root, Hausman, Hansen J and AR(2) tests.
  • Found broadband's growth effect to be over 4× that of mobile and an inverted-U ICT–employment relationship; translated results into policy recommendations.

Global Data Salaries, 2020–2023 R Project

Course Final Project — Dec 2025 · 3,761 salary records
RData CleaningDashboard

What do data jobs pay, and what drives the difference? I combined four yearly salary files into one dataset of 3,761 records across 93 job titles and 72 countries, audited it for missing values and outliers, and published the results two ways: a reproducible R Markdown report and an interactive Shiny dashboard.

  • Merged four yearly Excel files (2020–2023) into a single dataset with readxl, then measured the missing-value rate of every column: 0% missing, so all 3,761 rows were kept.
  • Wrote a reusable 1.5×IQR outlier function and ran it on every numeric column; it flags 63 salaries above $295,000.
  • Built a summary-statistics function (min, max, mean, median, standard deviation) and ggplot2 histograms for each numeric variable.
  • Knitted one R Markdown source to HTML, Word and PDF, with a plain-language explanation under every code chunk.
  • Built a flexdashboard + Shiny dashboard with plotly charts: pay by job title (exportable to Excel/PDF), by company size and by country, plus a USD→PKR view for a local reader.

3.1

Retail SQL Analytics Live

Personal Project — Oct 2026 · 1M sales lines, queried in the browser
SQLCustomer AnalyticsDashboard

Two years of real transactions from a UK online gift wholesaler, over a million sales lines. I cleaned the data with SQL and wrote ten SQL queries that each answer one business question. The dashboard runs a full SQL database inside the visitor's browser, so every filter re-runs the queries live and every chart shows the SQL behind it.

  • Cleaned 1,067,371 raw rows in SQL: removed a 22,523-row overlap between the two Excel sheets, postage and fee lines, and 11,792 duplicate scans, with every rule documented.
  • Wrote the core customer analyses in SQL: cohort retention, RFM segmentation, market-basket lift, and a Lorenz curve with the Gini coefficient (0.74, because the top 20% of customers bring 77% of revenue).
  • Runs DuckDB compiled to WebAssembly in the browser: no server, the data loads as 5.4 MB of Parquet, and a built-in SQL playground lets anyone write their own queries.
  • Found the story behind the numbers: the worst "return rate" is one 74,215-jar order cancelled 16 minutes later, not a bad product.
  • The same .sql files run in a Python test on GitHub Actions, so a broken query fails the build.

3.2

Crypto Sentiment Dashboard Live

Personal Project — Oct 2026 · updates every 6 hours
Data PipelineNLPDashboard

What are crypto news and Reddit saying about Bitcoin, Ethereum and Solana, and does the mood line up with the price? I built an automated pipeline that collects headlines and posts from 11 free sources, scores their sentiment, and lines it up against market prices in an interactive dashboard.

v1 · OriginalLive dashboard ↗ v2 · RedesignLive dashboard ↗
  • Collects from 11 sources with no API keys: CoinDesk, Cointelegraph, Decrypt and Google News feeds, four subreddits, and Yahoo Finance prices.
  • Runs every 6 hours on GitHub Actions, committing new data back to the repository, so the dataset grows on its own.
  • Scores sentiment with VADER NLP extended with a custom crypto lexicon (bullish, rekt, FUD, liquidated), and de-duplicates stories syndicated across outlets.
  • Handles real-world failure: reads Reddit's rate-limit headers and waits, and keeps running when a single source is down.
  • Keeps the statistics honest: low-sample days are faded or excluded, and the sentiment-vs-next-day-return correlation only appears once there is enough data.
  • A v2 redesign adds daily candlestick charts with each day's mood underneath, a sentiment gauge and per-coin sparkline cards, themed with custom CSS on top of Streamlit. Both versions are live.
