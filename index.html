Website Performance & SEO Audit Delivered

iAC Studio — Freelance · Jun – Aug 2026
Freelance Data Analyst

iAC Studio needed to know where its website was losing speed and search visibility — and what to fix first. I built an automated, reproducible audit that pulls live data from several sources, scores the site on mobile and desktop, and converts every finding into a prioritized action plan.

  • Built an automated, reproducible audit report in R Markdown pulling live data from the Google PageSpeed Insights API, HTML scraping (rvest) and server response headers.
  • Measured Lighthouse scores and Core Web Vitals across mobile and desktop to pinpoint where the site was losing speed and search visibility.
  • Audited on-page SEO — title/meta tags, heading hierarchy, link profile, image alt-text coverage — plus security headers and the site's technology stack.
  • Developed rule-based logic that converts findings into a High/Medium priority action plan, delivered as HTML, Word and PDF with ggplot2 charts.

2.1

ICT & Economic Development in 50 Developing Countries Research

Research Project — 2010–2022 panel data
ResearcherEconometrician

Which kinds of ICT drive economic growth, and what do they do to employment? I assembled the panel myself, solved a multicollinearity problem with a composite index, and estimated dynamic growth models and fixed-effects employment models — then validated them with a full battery of diagnostic tests.

  • Assembled a 650-observation country-year panel from World Bank (WDI), ITU, ILO and Worldwide Governance Indicators data.
  • Constructed a composite ICT index using Principal Component Analysis (71.6% variance explained) to resolve multicollinearity flagged by VIF testing.
  • Estimated two-step System GMM growth models and fixed-effects employment models, validated with IPS unit-root, Hausman, Hansen J and AR(2) tests.
  • Found broadband's growth effect to be over 4× that of mobile and an inverted-U ICT–employment relationship; translated results into policy recommendations.
